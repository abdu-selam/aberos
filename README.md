# Aberos PLC

A modern corporate website built for Aberos PLC, designed to present the company, its story, values, businesses, and contact information through a clean and responsive interface.

## Overview

The website provides information about Aberos PLC and its different business areas. It includes dedicated pages for the company overview, history, mission and vision, companies, and contact information.

The interface focuses on modern typography, smooth animations, responsive layouts, and interactive visual effects.

## Features

* Responsive design
* Corporate pages
* Companies showcase
* Contact page and contact form
* Smooth page transitions and animations
* Custom visual effects
* Mobile-friendly navigation
* Responsive images and layouts

## Getting Started

### Prerequisites

Make sure you have Node.js and npm installed.

### Installation

Clone the repository:

```bash
git clone https://github.com/abdu-selam/aberos
cd aberos
```

Install dependencies:

```bash
npm install
```

### Development

Start the development server:

```bash
npm run dev
```

The application will be available at the local URL provided by Vite.

### Build

Create a production build:

```bash
npm run build
```

### Preview

Preview the production build locally:

```bash
npm run preview
```

## Pages

* `/` — Home
* `/about` — About Aberos PLC
* `/companies` — Companies and business areas
